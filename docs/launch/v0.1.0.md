# v0.1.0 — The Evidence-First Transition Path

## Who This Is For

This release is for software engineers with light machine-learning and Python
experience who want a practical path into model inference and robotics. The
core path works with simulation and cloud resources; access to a physical robot
is optional.

## What Is Verified

- [M0 — Translate Your Existing Software Skills](../milestones/m0-skill-translation.md):
  the published [gap map](../build-log/2026-07-26-software-skill-gap-map.md)
  connects existing software-engineering strengths to the work still needed
  for robotics inference.
- [M1 — Execute and Measure a Model](../milestones/m1-model-inference.md):
  the [measurement build log](../build-log/2026-07-26-measuring-model-inference.md)
  records a runnable inference measurement and its claim boundary.
- [M2 — Learn Robot Data and Policies with LeRobot](../milestones/m2-lerobot-data-policies.md):
  the [PushT evaluation](../build-log/2026-07-26-evaluating-a-robot-policy-without-hardware.md)
  ran three seeded episodes and recorded `0/3` successes, a 95% Wilson
  interval of `0.0–0.562`, and three `low_coverage` failures. This validates
  the evaluation and artifact-writing path, not policy quality.

## What Is Active

[M3 — Optional Real-Arm Capstone](../milestones/m3-real-arm-capstone.md) is
active. Supervised SO-ARM101 hardware bring-up is verified, while the
three-episode dataset pilot and inspection gate remain in progress. The
[current build log](../build-log/2026-07-26-bringing-up-the-so-arm101.md)
separates those completed and active phases.

## What Is Planned

- [M4 — Build the Robotics Inference Loop](../milestones/m4-robotics-inference-loop.md)
  will add a tested asynchronous loop with backpressure, stale-action
  handling, and observability.
- [M5 — Serve a Modern Language or VLA Model with SGLang](../milestones/m5-sglang-serving.md)
  will add measured latency, throughput, batching, and GPU-memory evidence.
- [M6 — Contribute and Present the Evidence](../milestones/m6-contribute-and-present.md)
  will add a credible upstream contribution and an artifact-backed portfolio
  narrative.

These milestones are planned, not verified.

## Start Here

Begin with [M0](../milestones/m0-skill-translation.md), choose a
[budget and hardware path](../budget-paths.md), and follow the
[milestone index](../milestones/README.md) in order. LeRobot comes before
SGLang so the serving work is grounded in robot-data and policy contracts.

## Reproduce and Critique

Use the commands and linked artifacts in each verified build log to inspect or
reproduce the evidence. When a result differs, report the environment, command,
observed output, and artifact links. Contributions and critical reproductions
are welcome through the [contribution guide](../../CONTRIBUTING.md) and
[contribution routes](../contributions.md); the goal is stronger evidence, not
unexamined agreement.

## Known Limitations

- The PushT result is only three episodes. Its wide Wilson interval, dirty
  source-tree provenance, unpinned Hub policy revision, and recorded LeRobot
  0.5.1 environment prevent a policy-quality or current-compatibility claim.
- Autonomous SO-ARM101 behavior is not demonstrated. Dataset collection,
  policy training, deployment, and autonomous evaluation remain unverified.
- SGLang performance is not demonstrated. M5 is planned, and no serving
  benchmark has been published.
- The asynchronous robotics inference loop and upstream contribution remain
  planned under M4 and M6.
