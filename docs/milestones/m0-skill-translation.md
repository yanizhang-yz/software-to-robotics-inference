# M0 — Translate Your Existing Software Skills

Status: planned

## Why This Matters

Translation turns existing engineering experience into an intentional learning plan.

## Prerequisites

Experience building and operating software services.

## Learn

Map API, data, reliability, and system-design experience to inference and robotics work.

## Build

Write a personal gap map that identifies the next skills to practice.

## Measure

Check that the map names concrete gaps, learning resources, and a next experiment.

## Present

Publish the gap map and explain the chosen route.

## Hardware-Free Path

Choose simulation and cloud work as the default route.

## Advanced Path

Add a hardware route only when safe access and supervision are available.

## Completion Gate

Completion gate: A personal gap map and selected simulation, cloud, and hardware path.

## Evidence

No evidence is recorded while this milestone is planned.
