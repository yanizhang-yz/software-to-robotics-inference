# M4 — Build the Robotics Inference Loop

Status: planned

## Why This Matters

Robotics inference is a time-sensitive loop that must remain safe under load and delay.

## Prerequisites

Complete M2 and understand the policy inputs and actions being exchanged.

## Learn

Learn asynchronous control, backpressure, stale actions, and loop observability.

## Build

Implement a bounded asynchronous sensor-to-policy-to-action loop.

## Measure

Test normal, overloaded, and stale-action conditions while recording loop signals.

## Present

Explain the control flow, safety decisions, and observed behavior.

## Hardware-Free Path

Exercise the loop with a simulator or synthetic observations.

## Advanced Path

Integrate a safely bounded real device after simulation testing.

## Completion Gate

Completion gate: A tested asynchronous loop with backpressure, stale-action behavior, and observability.

## Evidence

No evidence is recorded while this milestone is planned.
