# M5 — Serve a Modern Language or VLA Model with SGLang

Status: planned

## Why This Matters

Serving work makes model latency and resource tradeoffs visible and measurable.

## Prerequisites

Complete M2 and understand the policy or model workload to serve.

## Learn

Learn prefill, decode, KV cache behavior, batching, and memory pressure.

## Build

Deploy a measurable SGLang service for a language or VLA model.

## Measure

Measure latency, throughput, batching, and GPU memory under representative load.

## Present

Explain the service configuration and the observed tradeoffs.

## Hardware-Free Path

Serve a language model in a cloud or local GPU environment.

## Advanced Path

Serve a VLA workload that can later support a robotics loop.

## Completion Gate

Completion gate: A measured service explaining prefill/decode, KV cache, batching, GPU memory, and latency-throughput tradeoffs.
