# M3 — Optional Real-Arm Capstone

Status: active

## Why This Matters

The capstone connects policy development with safe, observed physical execution.

## Prerequisites

Complete M2, have safe SO-ARM101 access, and follow local safety procedures.

## Learn

Learn the operational risks of recording, training, deployment, and evaluation on a real arm.

## Build

Prepare a safely bounded SO-ARM101 task and the recording, training, and deployment workflow.

## Measure

Report success, failures, and timing for evaluated task runs.

## Present

Publish a safety-aware account of the task, results, and failure modes.

## Hardware-Free Path

Use the simulation or cloud path if arm access is unavailable.

## Advanced Path

Perform the real-arm task only with safe setup, supervision, and recovery procedures.

## Completion Gate

Completion gate: A safely recorded, trained, deployed, and evaluated SO-ARM101 task with failures and timing reported.
