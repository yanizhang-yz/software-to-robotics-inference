# M6 — Contribute and Present the Evidence

Status: planned

## Why This Matters

Public evidence turns learning artifacts into a credible engineering narrative.

## Prerequisites

Complete the relevant build milestones and have artifacts suitable for review.

## Learn

Learn contribution expectations and how to communicate technical evidence clearly.

## Build

Prepare a contribution, portfolio artifact, and interview-ready explanation.

## Measure

Verify that commands, committed artifacts, and claims agree.

## Present

Publish the contribution and present the portfolio evidence.

## Hardware-Free Path

Contribute documentation, benchmarks, tooling, or simulation work.

## Advanced Path

Include real-arm evidence when it can be shared safely and reproducibly.

## Completion Gate

Completion gate: A credible LeRobot or SGLang contribution plus artifact-backed portfolio and interview material.

## Evidence

No evidence is recorded while this milestone is planned.
