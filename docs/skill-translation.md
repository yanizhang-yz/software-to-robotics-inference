# Skill Translation

Your software engineering experience is directly useful in inference and
robotics when it is translated into the system behavior being built.

| Existing software skill | Inference or robotics application |
|---|---|
| APIs and microservices | Model-serving endpoints |
| Queues and concurrency | Dynamic batching and asynchronous policy loops |
| Caching | Model weights, KV caches, and observation buffers |
| Observability | Latency, throughput, GPU memory, and control frequency |
| Testing | Numerical checks, policy evaluation, and hardware-in-the-loop tests |
| Distributed systems | Cloud training and remote inference |
| Data pipelines | Robot demonstrations, episodes, datasets, and replay |
| Reliability engineering | Timeouts, stale actions, emergency stops, and recovery |
| System design | Sensor-to-model-to-action architectures |
