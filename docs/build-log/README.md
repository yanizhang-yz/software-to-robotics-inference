# Build Log Index

The build log is an index of published learning entries, not a substitute for
committed evidence. Add an entry only after its runnable artifact and results
are committed in a public repository.

## Entry Contract

Each entry must link to committed evidence and extract one reusable lesson.
It should also identify the milestone, command, environment, limitation, and
the evidence status from the source artifact. Do not copy benchmark results
into this index; link to the committed result instead.
