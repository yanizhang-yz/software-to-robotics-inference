# Software Engineer to Robotics Inference Engineer

An evidence-based, build-in-public path for experienced software engineers who
have light ML exposure but have not owned modern model serving or robot systems.

## Who This Is For

This guide is for software engineers who want a practical bridge into model
inference and robotics without assuming prior hardware ownership.

## What You Will Build

You will build reproducible inference measurements, inspect robot data and
policies, design an asynchronous robotics loop, and publish evidence for each
completed milestone.

## Choose Your Path

Simulation and cloud work are the core path and are sufficient for every
milestone. SO-ARM101 is the advanced capstone for people who can safely access
hardware. Follow LeRobot before SGLang: robot data and policies in M2 establish
the context that later makes serving choices in M5 meaningful.

## Milestones

The ordered path is [M0](docs/milestones/m0-skill-translation.md) through
[M6](docs/milestones/m6-contribute-and-present.md). The complete overview is
in [the milestone index](docs/milestones/README.md).

## Evidence Repositories

Keep runnable artifacts, measurement commands, and committed results in public
repositories. A verified milestone links to a public GitHub blob artifact.

## Current Maintainer Progress

M3, the optional real-arm capstone, is active. The remaining milestones are
planned; see the canonical status records in `data/milestones.json`.

## Start Here

Begin with [M0](docs/milestones/m0-skill-translation.md), choose the
simulation, cloud, and hardware route that fits your constraints, then proceed
in milestone order.
